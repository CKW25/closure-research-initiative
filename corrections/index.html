Record Policy

The current PDFs, source bundles, citation metadata, and DOI records are the active public record. Earlier PDFs and source files are retained as fixed archived versions on the relevant work page. A superseded version remains citable for version-specific discussion, but the current version is the recommended citation target unless a claim depends on an earlier text.

Current record

The current monograph and preprints are listed on Preprints and Sources and Citation. Each work page gives the current PDF, source bundle, DOI, BibTeX record, and version history.

Archived versions

Superseded PDFs and source bundles are fixed archive files. Archive DOIs remain attached to the version for which they were issued and are not used as current citation targets.

Corrections

Corrections to definitions, hypotheses, proofs, citations, figures, or metadata are made in the next public version of the relevant work. The version history on that work page records the change at release level.

Errata reports

Public errata should identify the work, version, section, theorem or definition label, page number when available, and proposed correction. Reports may be opened through GitHub Issues or Discussions; private correspondence may be sent through Contact.

Citation practice

For current claims, cite the current work page and DOI. For historical comparison, cite the archived version and its DOI if one was issued. The consolidated citation map is maintained on Sources and Citation.

Current Errata
